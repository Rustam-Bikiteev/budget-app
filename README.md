# Бюджет

Статичное веб-приложение для учёта бюджета по полумесяцам.
Хостится на GitHub Pages, данные — в Supabase (Postgres + Auth).

Сервера нет: `index.html` ходит в Supabase напрямую через PostgREST.

## Стек

- vanilla JS, без сборки и зависимостей
- [supabase-js](https://github.com/supabase/supabase-js) с CDN
- Supabase Auth (email + пароль), доступ режет RLS
- PWA: ставится на домашний экран телефона

## Файлы

```
index.html             — версия с Supabase: разметка, хранилище, вход, realtime
app.js / app.css       — свой интерфейс версии с Supabase поверх shared/ (сводка «Свободно»,
                         кошельки «Я + Общие» и «Насте», оплата обязательных, свайпы)
shared/core.js         — общая логика обеих версий (расчёты, отрисовка, календарь, бэклог)
shared/core.css        — общий интерфейс обеих версий
manifest.webmanifest   — PWA-манифест
icon-192.png / icon-512.png
supabase_setup.sql     — включение RLS и политик (выполнить один раз)
supabase_add_transferred.sql — колонка months.transferred для отметки перевода Насте
```

`app.js` подключается после `shared/core.js` и объявляет функции с теми же именами
(`renderSummary`, `renderPlanned`, `saveEntry`...): core вызывает их по имени, поэтому
работает версия из `app.js`. `free/` подключает только `shared/` и этого не видит.

Период = спринт между выплатами: 1-я половина месяца — 10–24, 2-я — с 25-го по 9-е
следующего месяца. С 1 по 9 число открывается 2-я половина прошлого месяца.

## Схема данных

| Таблица   | Назначение |
|-----------|------------|
| `months`  | период (year / month / half), `income`, `saved` (цель отложить), `transferred` (сколько переведено Насте, null — не переводил) |
| `entries` | строки периода: `type` = `mandatory` / `planned`, `category` = `me` / `nastya` / `shared`. У обязательных `actual >= planned` = оплачено |
| `backlog` | отложенные траты вне периода |

Обязательная строка с «непредвид» в названии — резерв, а не платёж: её `actual` = сколько
из резерва уже взяли. Перерасход по трате (красное «Осталось») кликом покрывается из
`months.saved` или из этого резерва: план траты поднимается до факта, источник уменьшается.

## Общедоступная версия (`free/`)

`free/index.html` — local-first версия для всех желающих. Интерфейс и логику берёт
из `shared/`, поэтому правка там меняет обе версии; в `free/index.html` — только
хранилище IndexedDB, резервные копии и настройки категорий.
https://rustam-bikiteev.github.io/budget-app/free/

- без регистрации и сервера: данные в IndexedDB браузера пользователя
- категории настраиваются (название + цвет)
- составные операции (перенос в бэклог, копирование плана, восстановление) — одной транзакцией
- `navigator.storage.persist()` — браузер не вычистит данные сам при нехватке места
- ручную очистку данных сайта запретить нельзя, поэтому защита — резервные копии:
  - «Сохранить копию» (JSON; на телефоне через «Поделиться»)
  - автосохранение в выбранный файл после каждой правки (Chrome / Edge на компьютере)
  - напоминание, если копии нет больше 3 дней
  - «Восстановить из файла» с проверкой файла и откатом к прежним данным
- `free/sw.js` — офлайн-кэш оболочки (network-first)

## Развёртывание

1. Выполнить `supabase_setup.sql` в Supabase → SQL Editor
2. Завести пользователя в Authentication → Users
3. Settings → Pages → Source: `master`, папка `/ (root)`

Anon-ключ в `index.html` публичен по замыслу — доступ к данным
определяется исключительно RLS-политиками.
