# Выпуск Budget

Состояние на 23.11.2026. Этапы отражают готовность рабочей копии.

## Текущие этапы

| Этап | Результат | Статус |
|---|---|---|
| 1. Проверки | Общий gate, браузерные сценарии обоих режимов и workflow Pages | Готов локально |
| 2. UX | План, выделенная сумма и остатки, состояния записи, первый запуск | Готов локально |
| 3. Модули | ES modules, общие расчёты, явные интерфейсы UI и хранилищ | Готов локально |
| 4а. Схема и перенос | Семьи, роли, RLS, атомарные RPC, приглашения и перенос legacy | Готов локально |
| 4б. Облако | Вход и выбор семьи, подключение RPC, версии строк и повторы запросов | Готов локально |
| 5. Сопровождение | Карта проекта, запуск, проверка, выпуск и восстановление | Готов локально |
| 6. UI-компоненты и приёмка | Общие компоненты и воспроизводимая приёмка | Готов локально |

Последняя проверка SQL и Node: 72 теста. Последняя проверка UI: 12 Chrome E2E.
В обоих режимах проверены фокус, ввод сумм, диалоги и состояния записи.
Проверены desktop и 320/390 px, скриншоты сохранены в `test-results/`.
Все четыре варианта демо открываются в Chrome.
`npm run package:pages` успешно собрал локальный артефакт. SQL/RLS и облачные
операции исполнены в PostgreSQL PGlite. Браузерные сценарии проверили IndexedDB,
обновление service worker, офлайн и облачный интерфейс с подставным SDK.
[Покрытие проверок](INDEX.md#тесты).

## Чек-лист выпуска

- [x] Рабочая копия проходит локальные проверки и собирает артефакт Pages.
- [x] GitHub Actions проверяет `codex/budget-release` на Linux с Chromium.
  [Первый успешный запуск](https://github.com/Rustam-Bikiteev/budget-app/actions/runs/45274052322).
- [x] Staging SQL. Из локальной копии восстановлены три таблицы бюджета и аккаунт
  владельца. После миграции совпали ID, содержимое и число строк (12 / 258 / 6).
  Проверены одноразовое приглашение, изоляция постороннего, публикация таблиц
  в Realtime, конфликт двух PostgreSQL-соединений и повтор с тем же UUID.
- [x] Staging API и браузер. Три тестовых аккаунта вошли через Supabase Auth.
  PostgREST подтвердил приглашение и изоляцию постороннего. Два участника
  вошли в приложение в Chrome, изменение суммы пришло второму через Realtime
  без перезагрузки. Посторонний события не получил. Тестовые записи удалены.
- [ ] Устройства. Проверить установку, офлайн и восстановление на Safari iOS и
  Chrome Android. Проверить системный выбор файла на desktop, отзыв разрешения
  и повторную выдачу, VoiceOver/TalkBack и экранную клавиатуру.
  [Чек-лист пилота](FREE_PILOT.md#проверка-на-реальных-устройствах).
- [x] Рабочая БД. Перед переносом снята свежая копия. В транзакции проверены
  совпадение записей (12 периодов, 258 трат и платежей, 6 будущих покупок),
  единственный владелец и публикация таблиц Realtime. После переноса проверены
  чтение от роли владельца и отказ анонимному запросу. Партнёр может присоединиться
  по приглашению.
  [Перенос и откат](ARCHITECTURE.md#миграция-старой-семьи).
- [x] Pages. Источник переключён на GitHub Actions. Проверки, сборка и первая
  публикация через workflow прошли. Оба режима доступны по прежним адресам.
  [Выпуск GitHub Actions](https://github.com/Rustam-Bikiteev/budget-app/actions/runs/45279640409).
