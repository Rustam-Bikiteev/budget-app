# Бесплатный пилот Budget

План владельцу, 16.11.2026. Только локальная версия `/free/`, один бюджет на одном
устройстве. Облачную регистрацию в пилот не включать. Этот документ не подтверждает
публикацию или проверки на реальных телефонах. Выполненные проверки и ограничения
описаны в [аудите выпуска](RELEASE_REVIEW.md).

## Перед приглашением

- [ ] Зафиксировать версию кандидата и HTTPS-адрес `/free/`, проверить именно эту сборку.
- [ ] На первом запуске понятны полумесяцы, отсутствие синхронизации и место хранения данных.
- [ ] Видны версия, справка, способ связи с владельцем и инструкция установки PWA.
- [ ] Сообщение об экспорте не обещает сохранённую копию до фактического сохранения файла.
- [ ] Пользователь понимает: очистка данных сайта может удалить бюджет; защита браузера
  от вытеснения не заменяет внешнюю JSON-копию.
- [ ] Пройдены обязательные проверки проекта и ручные сценарии ниже на обеих платформах.
- [ ] Нет открытых ошибок потери данных, неверных итогов или невозможности восстановления.

## Проверка на реальных устройствах

Взять iPhone с Safari и Android с Chrome. Проверять обычный режим браузера и
установленную PWA. Эмуляция desktop-браузера эти проверки не заменяет. Записать
модель, версию ОС/браузера, версию приложения, дату, результат и шаги ошибки.
Использовать вымышленные данные; очистку выполнять только в отдельной тестовой среде
без личного бюджета. Если изолировать данные нельзя, сценарий пока не выполнять
и оставить непроверенным.

| Сценарий | Действия и критерий успеха |
|---|---|
| Установка | Открыть HTTPS-адрес. На iPhone через меню Safari добавить на экран «Домой»; на Android использовать предложенную Chrome установку или пункт меню. Открыть значок: загружается `/free/`, интерфейс доступен, клавиатура не перекрывает сохранение. Если пункта нет, записать фактическое поведение и оставить проверку установки незавершённой. |
| Обычный ввод | Создать период, доход 10000, накопления 1000, обязательную трату 2000, план 500 и категории с русскими названиями. Проверить итоги вручную, редактирование, перенос в список будущих покупок и обратно, удаление с подтверждением, смену периода. После закрытия и повторного открытия значения совпадают. |
| Браузер и PWA | Сначала создать тестовую запись в Safari/Chrome, затем открыть установленное приложение. Проверить видимость записи и правки в обоих режимах. Не обещать общее хранилище: если оно раздельное, объяснить перенос через копию и повторить его вручную. |
| Offline | После успешной онлайн-загрузки закрыть приложение, включить авиарежим, запустить с иконки. Данные и оболочка доступны; новая запись сохраняется после перезапуска без сети. Повторить для `/free/` и `/free/index.html` в браузере. Вернуть сеть: записи сохранились. |
| Внешняя копия | Нажать «Сохранить копию». На телефоне завершить сохранение через системный диалог/«Поделиться» в доступную папку. Найти JSON вне приложения, проверить имя и ненулевой размер. Отмена диалога не должна выглядеть как подтверждённая защита данных. |
| Restore | Импортировать сохранённый JSON в чистое тестовое хранилище. Сверить периоды, категории, доход, накопления, план/факт и будущие покупки. Перезапустить: всё сохранилось. Отдельно проверить отмену выбора файла и возврат к состоянию до восстановления. |
| Некорректный файл | Выбрать повреждённый JSON и файл другого формата. Понятная ошибка; прежний бюджет остаётся целым после перезапуска. |
| Потеря данных | Сначала убедиться, что внешняя копия доступна. Очистить данные тестового сайта средствами ОС/браузера, открыть приложение онлайн: прежние данные не ожидаются. Восстановить внешний JSON и сверить значения. Удаление одного значка PWA не считать доказанной очисткой хранилища. |
| Обновление | Оставить открытую предыдущую версию с введённым текстом, обновить тестовый хост до кандидата, вернуть приложение на экран. Нет потери ввода и сохранённых данных; после повторного запуска и offline открывается рабочая версия. |
| Ошибка хранения | В изолированном стенде воспроизвести отказ записи/квоту. Нет ложного успеха; старые данные целы, повтор после устранения отказа сохраняет правку. Если на телефоне отказ не воспроизведён, отметить ограничение отдельно от результата автоматического теста. |
| Доступность | Пройти основные действия с VoiceOver/TalkBack: поля подписаны, кнопки понятны, фокус модального окна управляем. Проверить увеличение текста и отсутствие горизонтального обрезания важных действий. |

Файловое автосохранение на desktop Chrome/Edge проверять отдельно, если оно
предлагается участникам: выбор файла, запись после изменения, повторное открытие,
отзыв разрешения и понятное сообщение об ошибке. На телефонах не обещать эту функцию.

## Пилот: 10–20 человек

1. После прохождения критериев владелец отдельно решает, публиковать ли кандидата
   и приглашать участников. Здесь публикация и приглашения не выполняются.
2. Набрать 10–20 добровольцев с обеими мобильными платформами. Первым 2–3 дать
   пройти весь путь самостоятельно; исправить блокеры перед остальными приглашениями.
3. На старте предложить создать небольшой бюджет и внешнюю копию, затем восстановить
   её в чистой тестовой среде. До успешного восстановления не полагаться на приложение
   как на единственное место хранения бюджета.
4. Вести пилот минимум два перехода между полумесяцами, ориентировочно 4–6 недель.
   Попросить проверить использование после выплаты и возврат в следующий период.
5. Собирать добровольные ответы через выбранный владельцем канал. В сводке оставить
   только количество результатов, платформу и обезличенные проблемы. Не запрашивать
   реальные суммы, названия трат, файлы копий, контакты или скриншоты личного бюджета.
   Для ошибки достаточно шагов на вымышленных данных и версии приложения.
6. При потере данных остановить расширение группы, разобраться с причиной, подготовить
   исправление и повторить затронутые проверки перед продолжением.

## Что спросить

- Получилось ли без подсказок создать бюджет, сохранить внешний JSON и восстановить его?
- Как ты понимаешь первую и вторую половину месяца? Где ожидал другой период?
- Было ли понятно, что данные не синхронизируются и могут исчезнуть при очистке сайта?
- Получилось ли установить приложение и открыть его без интернета?
- Что не сохранилось, посчиталось неверно или заставило перепроверять результат?
- Вернулся ли ты в следующий период? Если нет, что помешало?
- Какая одна правка сделала бы приложение полезнее для тебя?

## Решение после пилота

Это заранее выбранные критерии эксперимента, а не полученные показатели спроса.
Владелец считает результаты по добровольным ответам; молчание не означает успех.

- **Расширять бесплатный выпуск:** обе мобильные платформы прошли ручную проверку;
  нет нерешённых ошибок потери данных/расчётов/restore; не менее 80% ответивших
  справились с первым бюджетом и копией без помощи; не менее половины всей группы
  подтвердили возврат в следующий период. Для решения нужны ответы хотя бы 10 человек.
- **Повторить узкий пилот:** надёжность подтверждена, но непонятны периоды, установка
  или копии, либо ответов недостаточно. Исправить главный барьер и повторить проверку.
- **Остановить расширение:** есть потеря данных, неверные итоги или сломанное
  восстановление. Сначала исправление и повторная проверка на затронутых устройствах.

Успешный бесплатный пилот не подтверждает готовность облачного или платного продукта.
